# AI policy

prunecss is built with AI assistance, and AI tools are welcome in
contributions too. The full policy is in
[CONTRIBUTING.md](CONTRIBUTING.md#ai-assisted-contributions); in short:

- **The maintainer uses AI.** Much of the code is written together with
  Claude Code. Commits it helped with carry a `Co-Authored-By` line, and
  every change is reviewed by a human and passes the same tests, lints,
  fuzzing and coverage gates as any other.
- **Disclose it.** Say in your pull request which tool you used and how much.
- **You own every line.** Understand, test and be able to explain what you
  submit.
- **Write your own words** in issues, pull requests and review replies
  (translation tools are fine).
- **No autonomous agents.** A human reviews and submits every issue, pull
  request and comment.
- **Reproduce AI-found bugs** and include a minimal case before reporting.
- **Low-effort, unreviewed work may be closed** without a detailed review.

Instructions for AI coding agents working in this repository are in
[AGENTS.md](AGENTS.md).
